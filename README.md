### Структура плагина

## extension.js

файл с основным кодом плагина

при нажатии на сочетание клавиш ctrl + alt + f в нем вызывается функция activate, которая отвечает за всю работу плагина

внутри неё создаётся массив шрифтов, а после команда регистрируется в vscode с кодом, который она будет выполнять

с помощью функций из Math выбирается рандомный шрифт из массива, потом этот шрифт ставится на первое место в списке fontFamili, который отвечает за доступные шрифты в vscode, а остальные ставятся за ним, и vscode по дефолту делает активным шрифт, который стоит на 1 месте в этом списке

далее эти изменения кладутся в конфигурацию vscode

после блока кода комманды, этот код пушится в список доступных команд

## package.json

файл со всей технической информацией о плагине для vscode, чтобы ide знала, как называется плагин, где брать его исходный код, и какие клавиши используются для активации

## launch.json

файл конфигурации запуска плагина, как его запускать
